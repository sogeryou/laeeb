# 独立注册与登录：本地开发交付

日期：2026-10-09。上传目标：`sogeryou/laeeb` 的独立开发分支，不覆盖主分支。

## 已完成范围

- 独立全屏登录／注册页面：邮箱验证码、旧密码登录、基础资料、系统／裁剪上传头像、可选兴趣标签、找回／设置密码、受限账号入口。
- 注册前必须验证邮箱，资料与协议校验成功才创建 USER 和钱包；旧账号在原 ID 上补全，原钱包、订单、陪玩、等级与社交数据不另建。
- 出生日期由服务器日历校验满 18 周岁，不进入公开账号信息；昵称前后端统一按可见 Unicode 字符计数。
- 英语／阿拉伯语 RTL、原端内紫色、简短文案、步骤图标和可减少动画设置。移动与桌面布局分别适配。
- 访问凭据恢复／刷新／退出、当前设备会话整族撤销、重置密码撤销旧凭据；异步旧结果不能覆盖退出或新账号。
- 同账号刷新保留私信、动态及评论草稿；切换身份／退出清除私有缓存，旧钱包请求结果不能回填到新身份。
- 代码分层保留后续调整空间：表现、文案、步骤组件、流程状态、接口契约分开。

- 自动测试：31 个文件、119 项测试通过；完整套件连续重复三次全部通过，另八次并行认证接口套件共 176 项通过。覆盖会话并发、过期登录退出／刷新、密码重置、上传所有权、昵称、草稿和私有缓存回归。
- 前端类型检查、服务器编译、前端生产打包通过；政策校验通过，算法 golden 测试属于上述测试集且全部通过。
- 实际浏览器：新账号邮箱 → 验证码 → 系统头像／昵称／性别／成年生日 → 标签保存 → 首页；刷新后仍为同一账号，Me 显示注册头像与昵称。退出后进入独立登录，旧陪玩原密码登录进入原身份补全页。
- 375px 阿拉伯语资料页已截图；320px 检查页面宽度等于视口，没有横向溢出。日期使用原生日期控件，验证年龄上限来自服务器。
- HTTP 冒烟：healthz、ready、metrics、companions/rankings 均成功。测试使用独立临时目录和虚构邮箱，不写入原业务数据。

## 本地体验

`pnpm install --frozen-lockfile`，然后 `PORT=3002 pnpm dev:player-center`。打开 `http://localhost:3002/auth/register`。

预览脚本显式使用一次性测试数据、开发邮件与本地绑定，忽略生产邮件凭据。页面显示 Local email preview 仅供测试，不代表真实邮箱收到邮件。预览重启会创建新的测试目录；旧业务数据不被替换。

## 正式上线前仍须完成

1. 配置真实邮件供应商密钥和已验证发件人，实际邮箱送达与反垃圾验收；未配置时接口明确拒绝发码，不假装发送成功。
2. 生产会话使用持久化 Redis，头像目录挂载持久存储。现有业务 JSON 模型只支持单写进程；多实例前需事务化共享账号、钱包与验证码存储。
3. 正式条款与隐私文本审核，按正式版本更新协议；当前文本是产品开发说明，不是完整法律文本。
4. 真实内容风控供应商、注册漏斗埋点、废弃验证码／上传资源保留与清理策略，以及生产监控需要后续接入。本次未宣称已完成真实风控或生产上线。

当前账号凭据沿用端内浏览器存储方案，未改成 HttpOnly cookie；生产仍需执行 XSS／CSP 及依赖安全审查。初版遗留的设置页资料编辑、绑定账号等功能不属于此次重做范围，不能把原型按钮当作已实现业务。
