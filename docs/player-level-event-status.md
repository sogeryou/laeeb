# 陪玩等级事件接入进度（本地）

## 已接入

- 成功登录由服务端记录登录事件，同一平台自然日只计一次登录任务奖励；事件不保存登录凭据。
- 订单支付冻结成功时记录接单机会，陪玩接单时记录响应，以 5 分钟内响应计算接单率。
- 陪玩中心只返回当前登录陪玩的任务数据；没有接单机会时显示 `NO OPPORTUNITIES`，不等同于接单失败。
- 文字私信、历史记录、会话未读与已读接入真实接口；连续未回复消息合并为一次机会，以第一条服务端时间计算 5 分钟响应。
- 招呼任务接入真实文字私信：发送时该用户没有在该陪玩完成过订单，24 小时内回复才奖励；同一用户对同一陪玩终身仅奖励一次，每次 5 分、每周上限 50 分，按回复时间计入平台自然周。
- 文字动态发布和列表接入持久化；当前版本先审后发，首次审核通过记录 POST 事件，按通过时间的平台自然日去重，每日 5 分、每周上限 15 分。违规下架撤销资格，已结算周进入人工复核队列。
- 私信、动态写入失败回滚本次内存数据及事件；同一请求重试不重复创建，改变内容复用请求标识会被拒绝。
- 前端保留失败草稿；补齐离线超过 50 条消息的追赶、已读回执失败重试、发布成功与旧列表返回的并发保护。
- 正式等级与本周预估积分分离，历史陪玩未初始化时继续显示待同步，不擅自重置。
- 内部周结算函数校验完整自然周、结束后 5 分钟缓冲、来源完整标记、重复结算、周次重叠、跳周、输入有效性及暂停状态，保存结算前后记录。
