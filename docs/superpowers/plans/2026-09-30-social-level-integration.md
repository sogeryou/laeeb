# 私信、动态与等级任务接入计划

**Goal:** 保持已有页面，接入文字私信、文字动态及可信等级事件。

**Architecture:** Express 鉴权接口使用现有 JSON 状态持久化，React 页面轮询刷新；等级事件与业务数据在同一次保存中写入。连续未回复消息合并为一次机会，第一条开始计时，回复后才能开启下一次机会。

**Tech Stack:** TypeScript / Express / React / Vitest / Supertest。

## Global Constraints

- 本地开发，不提交、不上传 GitHub；登录注册不修改。
- 只接受服务端用户身份与时间；发送失败不计分，幂等键冲突拒绝。
- 私信历史仅双方可读；已读标记只能更新发给自己的消息。
- 本次文字私信、文字动态接入；礼物、图片、语音及招呼奖励保持未接通。
- 动态每日 5 分、每周 15 分；回复率复用已确认的 5 分钟阶梯规则。
