# 登录入口与发帖流程改版说明

日期：2026-10-15。基线：`cd45264e897ed4af917a82db78333b7240d731da`，原分支 `codex/independent-auth`。

用户已确认：先登录才能进入应用，注册不再选择兴趣标签，社区右上角作为发帖入口，使用独立发帖页。本文细化验收规则，不重新设计现有视觉，也不重写后台认证体系。

## 1. 唯一的用户端入口

- 未登录访问应用根页面时进入独立 `/auth/login`，不能先看到首页、社区、陪玩列表或底部导航。移除用户端游客浏览、返回应用和跳过登录的入口；用户端不再通过弹窗完成登录。
- 本地有凭证时，先验证现有会话。验证期间只显示加载状态，不提前渲染应用。会话有效且资料完整时直接进入应用，不要求每次重复登录。
- 网络故障或服务端暂时异常不等同于凭证失效：保留凭证，停留在可重试的会话验证状态，不能放行应用，也不能反复自动跳转。用户可以主动退出后重新登录。
- 会话明确失效且现有刷新机制无法恢复时返回登录页。退出登录立即隐藏应用并清除该账号私有界面状态；浏览器后退不能重新展示已退出账号的界面。
- 已认证但必要资料未完成的普通用户只进入完善资料页；受限账号进入现有受限说明页，不能绕过状态检查进入应用。保留现有验证码、密码登录、找回密码、年龄与条款校验、刷新凭证和后台权限规则。
- 沿用现有公开实体 ID 的登录后恢复机制，不将消息、订单数据或私有快照写入网址或返回记录。登录页、注册页及旧链接不能造成重定向循环。
- 本轮只统一用户端入口。独立 `/admin` 后台及其现有管理员登录、权限和拒绝普通用户的规则不改；不能为了删除用户端旧入口而误删后台仍使用的认证组件。
- 这是用户端访问门禁，不声称把所有公开 API 改成私有接口；现有后台 API 权限仍然独立执行。

## 2. 注册精简为两段

- 流程为邮箱验证 → 完善必要资料 → 直接进入应用首页。已有账号缺资料时也在补齐后直接完成，不再进入兴趣标签页。
- 从注册进度、页面、前进/后退逻辑和完成请求中移除兴趣标签步骤，不再调用兴趣偏好接口作为注册完成条件。
- 旧 `/auth/interests` 链接仅做兼容转向：未登录到登录页，资料未完成到资料页，完整有效会话完成入口恢复后进入应用。转向遵守同样的会话验证和受限账号规则。
- 不清空老用户已有兴趣标签，不修改账号 ID、角色、余额、陪玩审核资格或服务信息；不删除后台已有偏好接口与存量字段。

## 3. 社区右上角发帖

- 删除当前信息流中间的 Create post 按钮和展开式编辑表单。在社区顶部设置独立、固定可找到的发帖图标按钮，与列表标签留出清晰位置；使用现有图标库、可访问名称和悬停提示。阿拉伯文按 RTL 对齐，不挤压列表标签。
- 点击后进入独立的全屏发帖视图，不把编辑框插进信息流。编辑时隐藏社区列表与底部导航；顶部为取消和发布，正文为文本编辑区及字数状态。
- 本轮仍只支持现有纯文本发帖，最多 5000 字符；空白正文不可提交。没有真实接入的图片、视频、话题和上传控件不显示为可用功能。
- 取消或返回时回到原社区列表模式和标签，不清空本账号当前内存草稿；再次打开发帖恢复正文。不承诺刷新后保存草稿，不把草稿写入公共缓存；退出、换账号及失效会话清空私有草稿。
- 提交中防止重复点击，沿用现有请求标识和重复提交保护。失败留在编辑页，保留正文并展示可重试错误；退出、换账号、离开页面后的旧请求不能恢复旧账号草稿或跳转。
- 只有收到后台实际成功结果才离开发帖页并清空已提交正文。返回“我的帖子”查看真实审核状态；提示待审核不等于公开成功，不改变审核与积分发放规则。
- 提交与返回依赖当前有效账号；全局门禁失效后不能继续编辑或提交旧账号内容。保留当前真实帖子读取、作者身份、审核状态与已有社交接口。

## 4. 范围和视觉

保留现有 LE3EB 登录视觉、游戏素材、社区卡片和业务页面布局，仅调整入口、注册步骤、社区顶栏及发帖编辑流程。英文、阿拉伯文、键盘焦点和手机/桌面均须可用。已完成的真实陪玩筛选、个人资料、站内通知、聊天和订单能力不回退。

不新增依赖，不迁移生产数据，不发送真实邮件，不触发真实支付，不合并主分支，不部署上线。继续保护用户文件 `backend/routes/auth 2.ts` 和无关修改。代码验收后按原授权推送到 `sogeryou/laeeb` 的原分支，使用非强制更新并核对远端内容。

## 5. 验收清单

1. 无凭证、有效凭证、过期可刷新、明确失效、临时网络故障分别进入正确状态；加载和跳转期间不闪现应用，浏览器返回不绕过门禁。
2. 注册和补全资料后直接进首页，不出现兴趣标签，也不提交空标签覆盖老用户；旧兴趣链接正确转向，受限账号与管理员规则保持有效。
3. 社区顶部能找到发帖入口；独立编辑页能取消、恢复同账号草稿、限制空白和长度、正确显示提交中、失败重试及真实待审核结果。
4. 账号切换、退出、A-B-A 和延迟成功/失败不会串号、恢复旧草稿或重复发帖；取消编辑保留社区上下文。
5. 新行为先写失败回归测试，再实现修复。使用全新隔离本地数据，从登录到社区发帖、查看审核状态完整走通；不对生产数据或外部渠道执行操作。
6. 检查 EN/AR 在 320、375、1440 像素下的登录、注册、社区顶栏与发帖页，确认真实素材、焦点、按钮和文字无重叠、无横向溢出。
7. 全量自动化测试、前后端类型检查、构建和独立审查通过；验证历史订单、余额、角色、服务价格与已有资料不被改写。推送前确认提交内容与已验收版本一致。
