# 独立注册／登录设计 v0.3

日期：2026-10-08。状态：设计待确认，仅本地演示，不连接真实账号，不提交或上传 GitHub。

预览：[v0.3](http://localhost:8766/social-v3.html)。承接 [v0.2 交互规格](social-v2-design.md)，视觉与动效以本稿为准；产品规则以 PRD v1.1 及其最新修订为准。

## 本次调整

按用户最新要求恢复端内风格，不再沿用暖白／珊瑚色。主背景 `#0f071a` 来自 AppShell，紫色主操作与端内 purple-600 一致；不是将陪玩中心独有的绿色带到登录注册中。

| 元素 | 规格 |
| --- | --- |
| 页面／表单 | 深紫 `#0f071a`／`#171022`；输入 `#21172f` |
| 主按钮 | 紫色 `#9333ea`，白字，52px 最小高度，14px 圆角 |
| 正文／辅助 | `#f7f3ff`／`#b4a8c5`；必要辅助信息至少 12px |
| 输入边框／焦点 | `#7b6888`／`#c9a2ff`；不去除键盘焦点 |
| 错误 | `#ffafbc`＋错误标识＋可读恢复指引，不仅变红 |

保留真实相处氛围图，但去掉侧图的大标题、两行标语和重复引导，用游戏／对话／陪伴三枚同风格 SVG 标识表达氛围。图片仍是虚构成年人物示意，来源说明留在评审区域，不作为用户证言。

## 文字与图标

- 注册每步只保留一个短标题；邮箱、资料、标签通过三个图标节点、连接线和短标签定位。完成节点变为勾，不仅靠颜色变化。
- CTA 使用简短 Continue＋方向箭头，仍有可读名称，不把提交操作变成无法理解的纯图标。
- 头像保留“Choose avatar”入口及“Photo or system avatar”，去掉三层重复说明；两个头像来源仍同等允许。
- 保留昵称／性别／生日标签、18+ 与完整生日私密提示、协议选择、邮件有效期、网络和字段错误。精简不等于删除风险说明。
- 标签仍是推荐 3、最多 5、允许跳过的待确认方案，没有新增业务决定。

## 动效与连续性

| 行为 | 演示规格 |
| --- | --- |
| 前进／返回 | 表单内容 260ms，透明度＋16px 水平位移；返回反向，阿语镜像 |
| 头像选择面板 | 240ms 透明度＋12px 上移与 0.98→1 缩放；支持关闭／Escape |
| 头像选定 | 220ms 透明度＋0.92→1 轻缩放，立即回显 |
| 标签／性别选择 | 180ms 颜色／边框过渡；标签加号切为勾，保留 aria-pressed |
| 点击 | 160ms 轻微按压；不改变布局占位 |
| 减少动态效果 | CSS 与脚本同时尊重系统偏好，停用转场／缩放；加载仍有静态状态标识与文字 |

不使用持续漂浮、霓虹闪烁、逐字段延迟出现或强制等待动画。输入过程中不重建表单；切页立刻可操作，动画不锁输入，回退保留当前页内草稿。清空敏感输入、真实接口与安全状态恢复将在业务实现阶段处理。

## 范围与后续

本轮仅新增设计 HTML、调整预览入口并补充文档；原首页、陪玩中心、登录后端未改动。设计稿不发邮件、不验真实验证码、不建号、不改密码、不上传图片；照片只能由用户主动选择后在当前页面预览。

先确认本稿视觉与动效，再形成真实前后端实施计划。验收记录见 [v0.3 检查](social-v3-validation.md)。系统头像和年龄门槛沿用已确认条件，不重复决策。
