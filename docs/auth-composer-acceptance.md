# 登录门禁与独立发帖：验收记录

日期：2026-10-21。范围以已确认的 `docs/superpowers/specs/2026-10-15-auth-gate-and-post-composer-design.md` 为准。本次不改变原有紫色视觉、后台权限、订单资金或帖子审核规则。

## 本次实现

- 用户端先验证当前会话才挂载应用；未登录、资料未完善、受限账号不显示应用内容。临时网络故障保留凭据，显示重试／退出。后台 `/admin` 仍走独立入口。
- 注册为邮箱验证 → 必要资料 → 进入应用；不再出现兴趣步骤，不调用偏好接口，也不清空老标签。旧兴趣链接只做受控转向。
- 社区顶栏固定发帖图标，进入独立纯文本编辑页；取消保留社区筛选和本账号内存草稿并恢复焦点。空白／超5000字符不能提交，编辑时无底部导航。
- 发帖失败保留正文和同一请求标识；只有实际有效回执才返回“我的帖子”显示真实审核状态。待审核不是公开成功。退出、换号、A-B-A、凭据轮换、取消或离开后的旧请求不能错误回填或跳转。
